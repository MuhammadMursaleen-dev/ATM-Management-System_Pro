# 🏦 ATM Management System (Python)

A Professional ATM Management System built with Python using JSON file handling.

## 📌 Features

- ✅ Create Account
- ✅ Login Account
- ✅ Search Account
- ✅ Show All Accounts
- ✅ Check Balance
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Transfer Money
- ✅ Change PIN
- ✅ Transaction History
- ✅ Delete Account
- ✅ Account Lock after 3 Wrong PIN Attempts
- ✅ JSON Database Storage

---

## 🛠 Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Modules

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/MuhammadMursaleen-dev/ATM-Management-System_Pro.git
```

2. Open the project folder.

3. Run

```bash
python main.py
```
